**p4n4-dashboard 1.3.0** is made for shared screens and the people who run them: kiosk mode for wall tablets, settings for each view, tools for managing accounts, and a vision overlay that raises alerts on every tab.

```bash
docker pull ghcr.io/raisga/p4n4-dashboard:1.3.0    # amd64 and arm64
```

> **Trusted networks only,** like the rest of p4n4. Keep port 8088 on your LAN. If it must be reachable from elsewhere, serve it over HTTPS (`docker-compose.tls.yml`) with basic auth on.

## Highlights

- **Kiosk mode** (Settings → This device): an admin signs a wall tablet in with a viewer account.
  - It has no Sign out, theme toggle or tour, and Settings holds only Accessibility.
  - A lock button takes an admin's sign-in to leave.
  - After a few idle minutes (5 by default) it starts over: start tab, conversation cleared, text size back.
  - On any device, admins and power users can be signed out when idle.
- **View settings** (Settings → Views): besides its tabs, each of the power and normie views gets:
  - the tab it opens on;
  - which of Home's cards it shows;
  - its own Grafana page (normies always get kiosk mode);
  - its cameras and whether the vision overlay is drawn;
  - which alerts pop up and whether they chime.

  p4n4-api keeps them, and devices pick up changes to them, and to the tabs, within a minute.
- **Account tools for admins** (Settings → Users, Banner, Audit log):
  - Each account's last sign-in.
  - **Sign out everywhere**, keeping the password.
  - A reset or a new account can require a new password; the user then gets only the password form after signing in.
  - A **banner** above every view on every device, info or warning, until cleared or for 1, 4 or 24 hours.
  - The **audit log**, a page at a time.
- **Change password** in Settings → Account, for anyone signed in with a p4n4-api account.
- **Personal defaults** (Settings → Appearance, admins and power users): the tab this device opens on, the Device tab's chart history (2, 10 or 30 minutes) and the default camera.
- **Vision overlay:** with `dashboard.vision` in `.p4n4.json`, the Video tab draws what the project's vision model sees.
  - Each person gets a box, their behaviour and their zone, from a camera's recording or a live stream of detections.
  - A behaviour that asks for an alert pulses on its camera and pops up as a toast on every tab. A risk chimes; Settings → Endpoints → Cameras → Alert sound turns that off.
  - New pending alerts in the Feed toast the same way. Tapping a toast opens its camera, or the Feed.
- **Cameras** open on all of them in a grid by default (Settings → Appearance → Open on all cameras).
- **Chats** (Settings → Chats, admins): link and unlink the chats a project's bot serves, when `.p4n4.json` names its chats service in `dashboard.chats`.
- **Demo build:** `--dart-define=P4N4_DEMO=true` answers p4n4-api's endpoints in the browser from a recorded `demo/store.json`, so a preview needs no stack behind it.

## Compatibility

- Needs **p4n4-api 0.3.0** for view settings, the banner, the account tools, chats and the vision overlay.
- `.env.example` pins `DASHBOARD_VERSION=1.3.0`.

## Upgrading from 1.2.0

- Upgrade p4n4-api to 0.3.0 first.
- Set `DASHBOARD_VERSION=1.3.0` in the dashboard layer's `.env`.
- The normie view's Grafana tab is always in kiosk mode now, whatever the deployment's setting.
- Kiosk mode needs p4n4-api accounts: with `P4N4_API_AUTH=off`, nobody could leave it, so it can't be turned on.

## Limitations

- Touches inside the embedded Grafana page don't reach the dashboard, so they don't count as activity for a kiosk's idle reset. Pick a start-over time longer than a look at a chart.
- The new labels in languages other than English haven't been reviewed by native speakers.
